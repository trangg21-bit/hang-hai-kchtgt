## Key technical decisions

| Decision | Reason | Trade-off |
|----------|--------|-----------|
| Use `@RequiredArgsConstructor` + `private final` in all services | Matches existing service patterns; Lombok auto-generates constructor | None — consistent with codebase |
| `orgUnitCacheService.getName(UUID)` returns null when id is null | OrgUnitCacheService.getName() already handles null input | Cleaner than manual null-check |
| `orgUnitCacheService.getDirectory()` returns `Map.copyOf` (immutable) | Wrapping in `new HashMap<>(...)` allows mutation if downstream code needs it | Slight memory overhead for copy; safe for current usage |
| BeaconLightService/BuoyService: removed `OrgUnitRepository` import entirely | No other usage of `orgUnitRepo` / `OrgUnitRepository` in those files | Clean removal |
| KchtGis155Service: removed try/catch with log warning | `getDirectory()` throws if cache misconfigured (fail-fast) | Loses graceful degradation of the old catch; cache config is a startup invariant |
